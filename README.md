# JM-Orgue — Virtual Pipe Organ

JM-Orgue is een virtueel-pijporgel-app voor Windows: samples van echte orgels
(eigen sets, GrandOrgue- en Hauptwerk-imports) bespeelbaar via MIDI, met
registers, koppels, zwelkasten, generaal crescendo, galm/EQ per kanaal,
ASIO/WASAPI-uitvoer, extra registerschermen, MIDI-opname en live
muzieknotatie.

Gebouwd met Tauri 2 (Rust-backend) en Svelte 4 (frontend).

## Downloads

Installers (NSIS `-setup.exe` en MSI) staan bij de
[releases](../../releases). De app controleert zelf bij het opstarten of er
een nieuwere versie beschikbaar is.
